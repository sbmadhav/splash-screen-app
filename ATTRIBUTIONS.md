## How to Research Asset Sources

To find the original sources of the assets:

1. **For Images**: Use reverse image search tools like:
   - [Google Images](https://images.google.com/) (camera icon to upload)
   - [TinEye](https://tineye.com/)
   - [Bing Visual Search](https://www.bing.com/visualsearch)

2. **For Music**: Check metadata and common sources like:
   - [YouTube Audio Library](https://studio.youtube.com/channel/UC/music)
   - [Freesound](https://freesound.org/)
   - [Zapsplat](https://zapsplat.com/)
   - [Adobe Stock](https://stock.adobe.com/audio)

3. **Common License Types**:
   - **Creative Commons (CC0)**: Public domain, no attribution required
   - **Creative Commons (CC BY)**: Attribution required
   - **Royalty-free**: Paid license, check terms
   - **Custom/Commissioned**: Original work for this project
